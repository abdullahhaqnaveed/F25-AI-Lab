# Week 2 - Intelligent Agents and PEAS

Run:

```bash
python lab2_percepts.py
python lab2_check.py
```

lab2_percepts.py runs the reflex classroom agent on six percepts. lab2_model.py holds the
stateful agent. lab2_check.py runs the stateful agent on repeated percepts, both exact
boundaries, a mode change and an empty room, and prints the full trace. Lab2_Report.docx has
the PEAS specs, the environment classification and the trace.
