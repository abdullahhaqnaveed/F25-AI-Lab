# Week 1 - Introduction to AI and Paradigms

Run:

```bash
python lab1_compare.py
python lab1_rules.py
```

lab1_compare.py runs the symbolic rule and the probability threshold on four scholarship cases
and prints the disagreement table. lab1_rules.py runs the rule checker with two extra conditions
(fee clear and form signed) on four test cases and prints input, expected result, actual result
and reason. Lab1_Report.docx has the timeline, the tests and the comparison.
