# Week 3 - Uninformed Search

Run:

```bash
python lab3_bfs_dfs.py
python lab3_depth_search.py
python lab3_ucs.py
```

lab3_bfs_dfs.py runs BFS and DFS from A to G. lab3_depth_search.py runs DLS and IDDFS at
limits 1 to 4. lab3_ucs.py runs UCS on the weighted graph with the added C to G corridor and
compares it with the BFS route. Lab3_Report.docx has the hand traces and the results.
