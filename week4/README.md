# Week 4 - Informed Search, Heuristics and A*

Run:

```bash
python lab4_astar.py
python lab4_astar_audit.py
```

lab4_astar.py runs A* and UCS on the campus graph and prints paths, costs, processed order
and expansion counts. lab4_astar_audit.py checks the heuristic for admissibility and
consistency, prints the first three expansions by hand, and reruns A* with h(C) = 10.
Lab4_Report.docx has the hand calculations, the comparison table and the experiment.
