# Week 5 - Adversarial Search, Minimax and Alpha-Beta

Run:

```bash
python lab5_minimax.py
```

It runs minimax and alpha-beta on the tree with leaves 3, 5, 2, 9, 0, 7, 0, 0, then again on
the reordered tree, and prints the root value and the number of leaves checked in each run.
Lab5_Report.docx has the hand trace and the pruning comparison.
